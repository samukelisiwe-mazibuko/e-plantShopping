e-plantShopping

Project Name: Paradise Nursery - E-Plant Shopping Application

Overview

e-planting is a front-end React application called Paradise Nursery that allows users to browse a collection of houseplants and add them to a shopping cart. The application provides a simple and interactive shopping experience where users can manage plant quantities and view the total cost of their selected items.

Built using React and Redux Toolkit, the app demonstrates modern state management and component-based UI design.


Features
- Browse houseplants organized into categories
- Add plants to a shopping cart
- 
-Increase or decrease item quantity
- Remove items from cart
- Dynamic total price calculation
- Live cart item counter in navbar
- Navigation between Home, Products, and Cart pages
- Checkout button (Coming Soon feature)


Technologies Used
React (Frontend UI)
Redux Toolkit (State Management)
React Router (Navigation)
JavaScript (ES6+)
CSS (Styling)
